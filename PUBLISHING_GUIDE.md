# Publish Sammy Dandu's Portfolio on the Existing GitHub Pages Repository

Your GitHub account already has `sdandu2/sdandu2.github.io`, containing a course tutorial. Do not delete the course files or force push. This package adds the portfolio homepage without deleting any existing content.

1. Extract the ZIP into your PortfolioWebsite project directory.
2. Use the PowerShell commands in the accompanying ChatGPT reply to clone the existing repository, copy this site's files into it, and push an ordinary commit on `main`.
3. Visit **https://github.com/sdandu2/sdandu2.github.io/settings/pages** and set **Build and deployment → Source → GitHub Actions**.
4. Check the **Actions** tab for a successful `Publish portfolio to GitHub Pages` deployment.
5. Your site's expected address is **https://sdandu2.github.io/**, only after GitHub confirms successful deployment.

Any further push to `main` automatically deploys new content.

**Privacy note:** This is a public website. The email address, phone number, and résumé PDF will be public. Confirm these are what you intend to publish.
